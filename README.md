# Sistema de Comandas — Sprints 1 a 4 (integración)

**Inicio:** `python main.py` desde esta carpeta. Python 3.10+ y Tkinter.

**Documentación de autoría, tareas, arquitectura, integración y limitaciones:** abre `GUIA_CODIGO_Y_RESPONSABLES.md`.

**Pruebas:** `python -m unittest discover -p "prueba*.py" -v`. Además, `python prueba_aaron_sprint4.py` ejecuta las comprobaciones de Aarón.

**Advertencia:** es una integración de entregas estudiantiles. Se verificó sintaxis y pruebas automáticas de lógica; no se ejecutaron ventanas Tkinter en Windows. Haz respaldo de `restaurante.db` antes de iniciar. No usar credenciales de ejemplo para un restaurante real.
